# Office-31 dataset folder

Copy the extracted domain folders here. Each domain must have all 31 original
class directories in the same alphabetical order. Either layout works:

- `amazon/images/<class>/*.jpg` and `dslr/images/<class>/*.jpg`
- `amazon/<class>/*.jpg` and `dslr/<class>/*.jpg`

`webcam` is optional for the Amazon-to-DSLR experiment. Do not put the ZIP or TAR
archive here without extracting it. Keep the original class folder names.
No dataset images are included in this repository.
